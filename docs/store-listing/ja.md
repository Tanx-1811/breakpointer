# Chrome Web Store listing — 日本語

## Short description

レスポンシブチェック・テストツール：あらゆるサイトを複数の画面サイズで並べてプレビューし、レイアウトが崩れる正確な幅を見つけます。

## Detailed description

レイアウトが崩れる場所を、すべての画面サイズで一度に見つけましょう。

Breakpointerは、あらゆるWebサイトを複数のビューポートサイズで並べて、Chromeの中でそのまま表示します。各プレビューは実際のレイアウト幅と高さを持つため、メディアクエリやレスポンシブレイアウトは、そのサイズのウィンドウとまったく同じように動作します。

**すばやくプレビュー**
• ツールバーボタンをクリックして「このページをプレビュー」を選ぶ、任意のページやリンクを右クリックする、Alt+Shift+Pを押す、またはアドレスバーに「bpt」とURLを入力します。
• スマートフォン、折りたたみ端末、タブレット、ノートPC、デスクトップの一般的な28サイズ（名前やサイズで検索可能）に加え、任意のカスタムサイズにも対応。
• プレビューの端をドラッグしてサイズを変更すると、ページがリアルタイムでリフローします。サイズはブレークポイントにスナップします。
• Ctrl/⌘ + Kで、すべてのコマンド、サイズ、グループ、ページを検索できます。

**崩れる場所を見つける**
• レスポンシブスコア：すべてのページを0～100の1つの数値で評価。何が最も減点されているかを、監査、レポート、複数ページチェックで確認できます。
• メモ：任意のプレビューに問題点を貼り付け（Nキー）、ページ、ビューポートサイズ、メモをまとめた、すぐに貼り付けられるバグレポートをコピーできます。すべてのプレビューをメモ付きで1枚の画像として保存することもできます。
• 複数ページチェック：保存したページ、ページ内のリンク、サイトのサイトマップなど、ページの一覧全体をすべてのビューポートで一度にチェック。どのページがどのサイズで崩れるかを確認し、表をMarkdownとしてコピーするか、HTMLレポートをダウンロードできます。
• すべての幅をスキャン：範囲内のすべての幅でページをチェックし、各問題の最初と最後の幅をピクセル単位で特定します。結果はページの高さ、ブレークポイント、ビューポートとともにグラフに表示。最も悪い幅にワンクリックでビューポートを追加できます。
• 監査：すべてのサイズのすべての問題を1か所に集約。サイズごとのページ容量、リクエスト数、画像のピクセル数、Largest Contentful Paint、レイアウトシフトに加え、見出し・本文・ボタンのタイプスケールも表示し、どれもMarkdownの表としてコピーできます。
• レスポンシブ画像：すべての画像を、各ビューポートで表示される幅と照らし合わせて、大きすぎ、小さすぎ、適切なサイズのいずれかを判定。sizes属性の推奨値とsrcsetの推奨幅をコピーできます。
• ページの色の監査：テキスト、背景、枠線に使われている色をすべてのサイズにわたって一覧にし、CSS変数としてコピーできます。
• ビジュアルチェック：すべてのビューポートのベースラインを保存し、変更後に比較して、何が動いたかをピクセル単位で確認。並べて表示、スライダー、差分の枠表示から選べます。
• インスペクター：1つのプレビューで要素をクリックすると、そのサイズ、display、フォント、余白、レイアウトをすべてのサイズで比較。変化した部分がハイライトされます。2つ目の要素までの距離も、すべてのサイズで計測できます。
• ページ自身のCSSから読み取ったブレークポイントに加え、Tailwind、Bootstrap、Material UI、Chakra UI、Ant Design、Bulma、Foundation、または独自のブレークポイントに対応。すべてのビューポートにラベルを付け、各ブレークポイントの両側をテストできます。
• ライトとダークを並べて表示：任意のプレビューを、ページのライトスタイルまたはダークスタイルで表示できます。
• レスポンシブチェックで、横スクロール（とその原因の要素）、viewportタグの欠落、小さすぎるテキスト、小さなタッチターゲット、ボックスで切れたテキスト、低コントラストのテキスト、ぼやけた画像、画面を覆う要素、レイアウトシフトを検出し、ページ上で直接ハイライトします。
• 1つのプレビューをスクロールすると他のプレビューも同じ内容を表示し、リンクをクリックするとすべてのプレビューでそのページが開きます。
• レイアウトのアウトライン、カラムグリッド、ピクセルルーラー、スクロールバーの非表示、すべてのサイズに一度に適用されるライブCSS。よく使うCSSはスニペットとして保存できます。
• 2つのアドレスを比較：すべてのビューポートの隣に2つ目のプレビューを表示し（例：本番環境の隣にステージング環境）、同じページに追従します。
• 色覚特性やぼやけた視界、モーションの軽減やアニメーションの一時停止をシミュレートし、長い翻訳テキスト、右から左への表示、テキスト200%でレイアウトのストレステストができます。
• CSSピクセルで計測し、スポイトを使ってWCAG基準で色のコントラストを確認し、デザインのモックアップをプレビューに重ねてピクセル単位で比較できます。
• すべてのビューポートを正確なサイズの実際のウィンドウで開く（ログインが必要なサイト向け）、常に最前面のフローティングプレビューをエディターの横に置く、閲覧中のページをサイドパネルでプレビューする、といった使い方もできます。
• ページ全体のスクリーンショット、テキストの間隔（WCAG）、prefers-contrastと印刷スタイル、画像サイズとタブ順序のラベル、ベースライングリッド。

**見たものを共有**
• ショーケース画像：背景の上にシンプルなデバイスフレームで複数サイズのページを並べた画像。ポートフォリオ、クライアント、投稿にそのまま使えます。
• 1つのプレビューまたはワークスペースのスクリーンショット、すべてのビューポートをラベル付きで1枚にまとめた画像、クリップボードへのコピー、すべてのサイズとその問題をまとめたHTMLレポート。
• 任意のプレビューを正確なサイズの実際のウィンドウで開けます。

**自分のやり方で**
• 「決済QA」のようなビューポートグループを保存し、ワンクリックで切り替え。よく使われる画面サイズやWCAGリフローのサイズなど、8つの組み込みグループを用意しています。
• 1つのビューポートへのフォーカス、ページ間の戻る・進む、よくテストするページへの星付け、Ctrl/⌘ + ホイールでのズーム、Space + ドラッグでのパンが可能です。
• 再読み込みしても各プレビューのスクロール位置は保持され、自動で再読み込みすることもできます。ページをあなたのビューポートで開くワークスペースのリンクも共有できます。
• 構成をエクスポート・インポートして、チームと共有できます。
• すっきりしたライト／ダークデザイン、あらゆる操作に対応するキーボードショートカット。英語、スペイン語、ポルトガル語、フランス語、ドイツ語、日本語、インドネシア語、ベトナム語に対応。

**Breakpointer Pro**（7日間の無料トライアルあり。上記の機能はすべて無料のまま）
• すべてのサイズでのアクセシビリティチェック：altテキストのない画像、名前のないボタンやリンク（スマートフォンでのみ表示される、アイコンだけのメニューボタンによくあります）、ラベルのないフィールド、閉じたオフキャンバスメニューなど非表示要素へのキーボードフォーカス、ページ言語の未指定。
• クリックと入力を同期：1つのプレビューでメニューを開いたりフォームに入力したりすると、そのページのすべてのプレビューで同じ操作が行われます。フォームが二重送信されることはなく、パスワードや支払い情報のフィールドがコピーされることもありません。
• すっきりしたスクリーンショットとチェックのために、一般的な同意ツールのCookieバナーを非表示にします（何も同意しません）。
• プロジェクト：サイトごとにページ、ビューポート、ブレークポイント、グリッド、ライブCSS、比較を保存し、クライアント間をワンクリックで切り替え（プロジェクト1つは無料）。
• パフォーマンス予算：ページ容量、リクエスト数、LCP、CLSの上限を設定し、上限を超えたプレビューをすべて確認できます。
• クライアントに送るレポートや画像に、あなたのブランド（名前、ロゴ、リンク）を表示。
• 複数ページチェック、幅スキャン、監査のCSVとJSONエクスポート。
• ライセンスはブラウザ内で確認されます：アカウント不要、何も送信されません。

**プライバシーを重視した設計**
• アカウント、アナリティクス、サーバーは一切ありません。設定はブラウザ内に保存されます。
• インストール時にはどのサイトにもアクセスしません。他のページ内での表示をブロックするサイトがあり、ページ内のツールにも許可が必要です。必要なときにサイト（またはすべてのサイト）でBreakpointerを許可でき、Chromeを閉じるまでの一時的な許可も可能です。アクセスはいつでも削除できます。
• ビジュアルチェックのベースラインはブラウザ内に保存され、アップロードされることはありません。

**ご注意**
Breakpointerが変更するのはビューポートのサイズです。デバイスのユーザーエージェント、ピクセル密度、タッチ入力、ブラウザエンジンはエミュレートしません。ログイン状態やサードパーティCookieは、プレビュー内では動作が異なる場合があります。
