# Testing

## Automated

```sh
npm test            # unit tests (Vitest, jsdom)
npm run test:e2e    # builds dist + dist-e2e, then Playwright end-to-end and accessibility tests
npm run screenshots # regenerates store screenshots from the real UI (brand/store/screenshots)
```

The end-to-end suite loads the real extension into **Chrome for Testing**, Google's Chrome build for automation that Playwright bundles (156 at the time of writing). Branded Google Chrome (137 and later) no longer loads extensions from the command line, so testing in your everyday Chrome is manual: `chrome://extensions` → Developer mode → Load unpacked → `dist/`.

- **with-access** (`dist-e2e`): host access is granted in the manifest, as if the user allowed all sites, because automated tests can't click Chrome's permission prompt. Covers real viewport widths, blocked sites, frame-busting, workspace editing, groups, persistence, settings, screenshots, popup, axe checks the v0.2 tools (`tools.spec.ts`: synced scrolling and navigation, checks and highlights, outlines, live CSS, grid, custom breakpoints, edges, rotate all, saved pages, report, wheel zoom and pan) and the v0.3 features (`features.spec.ts`: command palette, back/forward, address suggestions, drag and keyboard resizing with snapping, focus mode, site breakpoints, inspector, page colours, hidden scrollbars, the all-in-one image and copying, sorting) and the utilities (`utilities.spec.ts`: comparing two addresses, vision simulations, measuring, the contrast checker, stress tests, reduced motion and paused animations, the image and fixed-cover checks, design overlays, CSS snippets and the new shortcuts, with axe checks of the new menus and dialogs in both themes).
- **no-access** (`dist`): the production build exactly as installed — checks the embedding notice, that blocked sites stay blocked, that screenshots explain the permission first, that in-frame tools offer to allow the site and run nothing without access, that vision simulations and measuring work without access (`utilities-no-access.spec.ts`), and that the manifest requests no host access.

Run headed with `HEADED=1 npx playwright test`.

## Release checklist

- [ ] `npm run lint && npm run format:check && npm run typecheck && npm test && npm run test:e2e` pass.
- [ ] `npm run package`; load the zip's contents unpacked in a clean profile; matrix above passes.
- [ ] `chrome://extensions` shows no errors; the install dialog shows **no** permission warnings.
- [ ] Permissions in the store listing match `src/manifest.ts`; privacy policy is up to date.
- [ ] No debug logging (only `console.warn` on failures).
- [ ] Version bumped in `package.json`; CHANGELOG updated; screenshots regenerated if the UI changed.
