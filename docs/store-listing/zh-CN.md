# Chrome Web Store listing — 简体中文

## Short description

响应式设计测试工具：在多种屏幕尺寸下并排预览任意网站，找出布局出问题的确切宽度。

## Detailed description

在每一种屏幕尺寸下，一次性找出布局在哪里出问题。

Breakpointer 直接在 Chrome 中，以多个视口尺寸并排显示任意网站。每个预览都有真实的布局宽度和高度，因此媒体查询和响应式布局的表现，与在该尺寸的窗口中完全一致。

**快速预览**
• 点击工具栏按钮并选择“预览此页面”，右键点击任意页面或链接，按 Alt+Shift+P，或在地址栏中输入“bpt”和网址。
• 内置 28 种常见尺寸，涵盖手机、折叠屏、平板、笔记本电脑和台式机（可按名称或尺寸搜索），也支持任意自定义尺寸。
• 拖动预览的边缘即可调整大小，并实时查看页面重排——它会吸附到你的断点。
• 按 Ctrl/⌘ + K 搜索所有命令、尺寸、分组和页面。
• 为长时间工作打造的工作区：带断点图的视口侧边栏、状态栏和小地图，三种布局（换行、单行、堆叠），六种强调色和三种画布样式。

**找出问题所在**
• 响应式评分：为每个页面给出 0 到 100 的一个分数——在审查、报告和批量检查页面中查看扣分最多的项目。
• 备注：在任意预览上标注问题（按 N），并复制可直接粘贴的缺陷报告，其中包含页面、视口尺寸和你的备注——也可以把所有预览连同备注保存为一张图片。
• 批量检查页面：一次性在每个视口下检查一整个页面列表——你保存的页面、某个页面上的链接或网站的站点地图。查看哪些页面在哪些尺寸下出问题，然后将表格复制为 Markdown，或下载 HTML 报告。
• 扫描所有宽度：在一个范围内的每个宽度检查页面，并精确到像素找出每个问题出现和消失的宽度——结果显示在图表上，同时标出页面高度、页面的断点和你的视口。一键即可在最差的宽度处添加视口。
• 审查：把每个尺寸下的所有问题集中在一处，并显示每个尺寸的页面体积、请求数、图片像素、最大内容绘制和布局偏移，以及标题、正文和按钮的字号体系——都可以复制为 Markdown 表格。
• 响应式图片：将每张图片与它在各个视口中的显示宽度对比——过大、过小或合适——并提供建议的 sizes 属性和 srcset 宽度，可直接复制。
• 页面颜色审查：汇总各尺寸下文字、背景和边框使用的颜色，并可复制为 CSS 变量。
• 元数据与社交：查看页面在搜索结果和链接预览中的大致显示效果，并检查其标题、描述、社交图片、canonical 地址、robots 和图标，同时显示标题的层级大纲。
• 视觉检查：为每个视口保存基准图，修改后进行对比，逐像素查看哪里发生了变化——并排显示、滑块对比，或用方框标出差异。
• 元素检查器：在一个预览中点击某个元素，即可对比它在每个尺寸下的大小、display、字体、间距和布局——发生变化的部分会高亮显示——还能测量它与第二个元素在每个尺寸下的距离。
• 断点读取自页面自身的 CSS，另外支持 Tailwind、Bootstrap、Material UI、Chakra UI、Ant Design、Bulma、Foundation 或你自己的断点——为每个视口添加标签，并测试每个断点的两侧。
• 浅色与深色并排：以页面的浅色或深色样式显示任意预览。
• 响应式检查可发现横向滚动（以及导致它的元素）、缺失的 viewport 标签、过小的文字、过小的触控目标、被容器截断的文字、低对比度文字、模糊的图片、遮挡屏幕的元素和布局偏移——并直接在页面中高亮显示。
• 滚动一个预览，其他预览会显示相同的内容；点击一个链接，所有预览都会打开它。
• 布局轮廓、列网格、像素标尺、隐藏滚动条和实时 CSS 可一次应用到所有尺寸——还可以把常用的 CSS 保存为代码片段。
• 对比两个地址：在每个视口旁边显示第二个预览，例如预发布环境与生产环境并排，并跟随相同的页面。
• 模拟色盲和视力模糊、减少动态效果和暂停动画，并用更长的翻译文本、从右到左的排版和 200% 的文字对布局进行压力测试。
• 以 CSS 像素测量，用取色器按 WCAG 检查颜色对比度，并把设计稿叠加在预览上逐像素对比。
• 将每个视口作为精确尺寸的真实窗口打开（适用于需要你登录的网站），在编辑器旁保留始终置顶的浮动预览，或在侧边栏面板中预览你正在浏览的页面。
• 整页截图、文字间距（WCAG）、prefers-contrast 和打印样式、图片尺寸和 Tab 键顺序标签，以及基线网格。

**分享你所看到的**
• 展示图：在背景上用简洁的设备边框展示页面在多种尺寸下的效果，可直接用于作品集、客户或社交帖子。
• 单个预览或工作区的截图、把所有视口合成一张带标签的图片、复制到剪贴板，以及包含每个尺寸及其问题的 HTML 报告。
• 将任意预览作为精确尺寸的真实窗口打开。

**按你的方式工作**
• 保存“结账流程测试”这样的视口分组，一键切换；内置八个分组，其中包括最常用的屏幕尺寸和 WCAG 重排尺寸。
• 聚焦单个视口，在页面之间后退和前进，为常测试的页面加星标，按 Ctrl/⌘ + 滚轮缩放，按空格 + 拖动平移。
• 重新加载后，每个预览仍保持原来的滚动位置，也可以自动重新加载；还可以分享工作区链接，用你的视口打开页面。
• 导出和导入你的设置，与团队共享。
• 简洁的浅色和深色设计，所有操作都有键盘快捷键，支持英语、西班牙语、葡萄牙语、法语、德语、日语、印度尼西亚语和越南语。

**Breakpointer Pro**（7 天免费试用；以上功能全部保持免费）
• 每个尺寸下的无障碍检查：没有 alt 文本的图片、没有名称的按钮和链接（通常是只在手机上显示、仅有图标的菜单按钮）、没有标签的字段、已关闭的屏外菜单等隐藏元素上的键盘焦点，以及缺失的页面语言。
• 同步点击和输入：在一个预览中打开菜单或填写表单，该页面的所有预览都会执行同样的操作——表单绝不会重复提交，密码和支付字段也绝不会被复制。
• 隐藏常见同意工具的 Cookie 横幅，以便获得干净的截图和检查结果（不会接受任何内容）。
• 项目：为每个网站保存页面、视口、断点、网格、实时 CSS 和对比设置，一键在客户之间切换（可免费使用一个项目）。
• 性能预算：为页面体积、请求数、LCP 和 CLS 设置上限，并查看所有超出上限的预览。
• 在发给客户的报告和图片上显示你的品牌——名称、徽标和链接。
• 批量检查页面、宽度扫描和审查结果的 CSV 和 JSON 导出。
• 许可证在你的浏览器中验证：无需账号，不会发送任何数据。

**注重隐私的设计**
• 没有账号、没有分析、没有服务器。设置保存在你的浏览器中。
• 安装时不会访问你的任何网站。有些网站会阻止在其他页面中显示，页面内的工具也需要你的许可；你可以在需要时允许 Breakpointer 访问某个网站（或所有网站）——也可以仅在 Chrome 关闭前有效——并可随时撤销访问权限。
• 视觉检查的基准图保存在你的浏览器中，绝不会上传。

**须知**
Breakpointer 只改变视口大小；它不会模拟设备的用户代理、像素密度、触控输入或浏览器引擎。登录状态和第三方 Cookie 在预览中的表现可能有所不同。
