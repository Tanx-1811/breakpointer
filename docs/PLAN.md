# Breakpointer — Product & Delivery Plan

> **Version:** 0.7.0 · **Status:** V1, the v0.2 inspection toolkit, the v0.3 redesign and pro toolkit, the v0.4 find, audit and verify release, the v0.5 whole-site and sharing release, the v0.6 **Breakpointer Pro** release and the v0.7 score, notes, projects and languages release, built and tested; **live on the Chrome Web Store** since 0.4.0 (17 Oct 2026, store at 0.5.0); 0.7.0 (with 0.6.0's Pro) ready to upload once the Pro checkout is set up, see [PRO.md](PRO.md)
> **Source:** refines the original planning brief (`plan.md`) into a delivery plan with decisions, status and acceptance criteria.

**Product goal:** help people check how a website looks at several viewport sizes, side by side, directly in Chrome — reliably, with minimal permissions, and honest about limits.

**Principle:** start with a reliable responsive preview workflow, then grow into a broader responsive testing toolkit.

## 4. Permissions and privacy

| Permission                            | When                     | Install warning              | Why                                                                                                                             |
| ------------------------------------- | ------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `storage`                             | Install                  | None                         | Save viewports, groups and preferences locally                                                                                  |
| `activeTab`                           | Install                  | None                         | Read the current tab's URL only when the user invokes Breakpointer                                                              |
| `contextMenus`                        | Install                  | None                         | "Preview in Breakpointer" on pages and links                                                                                    |
| `declarativeNetRequestWithHostAccess` | Install                  | None                         | Let previews of **allowed** sites ignore frame-blocking headers and Fetch Metadata frame checks, in the viewer tab only         |
| `sidePanel`                           | Install                  | None                         | Preview the page you're browsing in Chrome's side panel                                                                         |
| `scripting`                           | Install                  | None                         | Register the frame agent while a workspace is open; it only runs where host access was granted, and only acts in preview frames |
| Host access (`<all_urls>` subset)     | **Optional**, at runtime | Chrome prompt when requested | Per site: show blocked sites. All sites: also enables screenshots                                                               |

No data leaves the browser. v0.4 adds no permission: visual baselines use the extension's IndexedDB, and "until Chrome closes" uses the same optional host permission, removed by the service worker at the next start. v0.5 adds no permission either: Check pages uses the optional host access (several sites can be allowed in one prompt), sitemaps are read with that access, and `chrome.management.getSelf` (to link to the right store) needs none. v0.6 (Breakpointer Pro) adds no permission and no network request: licences are verified with WebCrypto in the browser, the Pro tools in previews use the frame agent on sites the user allowed, and “Get Pro” is an ordinary link to the seller's checkout. ## 7. Risks and mitigations

| Risk                               | Mitigation in V1                                                                                                                    | Next step                                                                     |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Many sites block framing           | Opt-in site access, clear notice, new-tab and exact-size-window fallbacks                                                           | Track "blocked" rate in feedback (M4)                                         |
| Users distrust "all sites" access  | Never requested at install; per-site option first; explained before Chrome's prompt; revocable in-app; "until Chrome closes" (v0.4) | Track how often people choose it (M4)                                         |
| Preview differs from a real device | Copy says "viewport", not "device"; help dialog lists what isn't emulated                                                           | V2 could add optional UA header per workspace                                 |
| Performance with many previews     | Max 8 viewports; hidden previews don't load at all                                                                                  | Measure memory on low-end machines; consider lazy-loading off-screen previews |
| Looks like existing tools          | Fast workflow, saved groups, breakpoint labels, honest errors, bilingual UI                                                         | Validate differentiators with testers                                         |
| Scope creep                        | V2–V4 kept as ideas behind feedback                                                                                                 | Re-prioritise after M4                                                        |
